🧪 Scraped Data Using Data Engineering Techniques
A complete Data Engineering pipeline to scrape lab data from Marham.pk, transform it using Pandas, load it into MySQL, and automate the process using Apache Airflow.

📌 Overview
Scrape lab details (name, location, services) using BeautifulSoup & Requests

Save raw data to a CSV file

Transform data using Pandas (cleaning, formatting)

Load into a MySQL database

Orchestrate the entire process using Apache Airflow DAGs

🔁 Workflow

Scrape → CSV → Transform → MySQL → Airflow DAG
